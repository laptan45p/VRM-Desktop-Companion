# VRM Desktop Companion

好きなVRMキャラクターをデスクトップに表示し、会話・しぐさ・音声を楽しむWindows向けマスコットアプリです。通常はキャラクターだけを表示し、発言は「伺か」のような吹き出しで届けます。

[ダウンロード](https://github.com/laptan45p/VRM-Desktop-Companion/releases/latest) · [詳しい使い方](USAGE.md) · [音声の導入](TTS_SETUP.md) · [更新履歴](UPDATE.md)

## できること

- VRM 0.x／1.0を表示し、移動・拡大縮小・XYZ回転。
- ローカルLLM、OpenAI、OpenRouter、OpenAI互換APIと会話。
- 入力ウィンドウで会話ログを読み返しながら、続けて会話。
- Irodori-TTSとSpeaker Embeddingで読み上げ。VRMを変えると登録した声も自動切り替え。
- .vrmaによる挨拶・ランダムモーション・待機ポーズ。
- 会話・ふれあいの自動表情と、登録された追加表情の一覧・強度付きプレビュー。
- タッチ反応、手や衣服のドラッグ、キャラクターごとの好感度・恋愛要素。
- スカート・コートの裾は中間からなだらかに曲がり、近くのボーン列も一緒に追従。

## はじめに

1. [Releases](https://github.com/laptan45p/VRM-Desktop-Companion/releases/latest)から **Windows-x64.zip** をダウンロードし、すべて展開します。
2. `VRM-Desktop-Companion.exe` を起動します。配布版ではNode.jsは不要です。
3. キャラクターの右クリック、またはタスクトレイのアイコンから「VRMを選ぶ」でモデルを読み込みます。未選択なら簡易デモキャラクターを表示します。
4. 「設定 → 会話用LLM」で接続先とモデルを設定し、保存します。
5. キャラクターを左クリックして入力ウィンドウを開き、話しかけます。

音声も使う場合は、下の「読み上げ」を設定してください。VRM、LLM、音声モデル、Speaker Embedding、モーションデータは同梱していません。

## 会話の接続先

| 接続方式 | 用意するもの | アプリの設定 |
| --- | --- | --- |
| Ollama | モデルを取得し、Ollamaを起動 | URL：`http://127.0.0.1:11434` |
| LM Studio | モデルを読み込み、ローカルサーバーを起動 | URL：`http://127.0.0.1:1234` |
| OpenAI API | OpenAIのAPIキー | 「OpenAI API」を選び、キーを登録 |
| OpenRouter | OpenRouterのAPIキー | 「OpenRouter」を選び、キーを登録 |
| OpenAI互換API | Chat Completions対応サービスのURL・キー | HTTPSのベースURLとキーを指定 |

「モデル一覧を取得」でモデルIDを選ぶか、直接入力して「設定を保存」を押します。一覧の取得はモデル本体のダウンロードではありません。クラウド接続では、先にAPIキーを登録してください。

Ollamaでモデルを用意する例：

```powershell
ollama pull qwen3:8b
```

接続や推論設定の詳細は[使い方ガイド](USAGE.md)をご覧ください。

## 基本操作

| 操作 | 動作 |
| --- | --- |
| 左クリック（反応部位以外） | 会話入力を開く |
| 右クリック／トレイのアイコンをクリック | 設定・VRM選択・終了などのメニュー |
| Shift＋ドラッグ | キャラクターを移動 |
| Ctrl＋ホイール | 拡大・縮小（0.5〜10倍） |
| Ctrl＋ドラッグ | X・Y軸を回転 |
| Ctrl＋Shift＋左右ドラッグ | Z軸を回転 |
| 吹き出し上部の名前欄をドラッグ | 吹き出しを移動 |
| Enter／Shift＋Enter | 送信／改行 |
| Esc（入力欄）／入力ウィンドウの× | 会話入力を閉じる |
| Ctrl＋Alt＋C | 会話入力を開く |
| Ctrl＋Alt＋M | キャラクターのクリック操作を無効化／解除 |

入力ウィンドウには会話ログと入力欄を表示し、送信後も開いたままにします。各ウィンドウの位置は個別に保存します。キャラクターを見失った場合はトレイの「位置をリセット」、完全終了するときは「終了」を選んでください。

キャラクター・会話ウィンドウ・吹き出しを手前に固定するには、「設定 → ウィンドウ → キャラクター・会話ウィンドウ・吹き出しを常に手前に表示」をオンにして保存します。右クリック・トレイメニューの「常に手前に表示」からもまとめて切り替えられ、次回起動後も保持します。

## 読み上げ

1. 初回は同梱の `install_irodori_tts.bat`、普段は `start_irodori_tts.bat` でIrodori-TTSサーバーを起動します。`tts-tools` フォルダーも必要です。
2. アプリの「設定 → Irodori-TTS 読み上げ」で有効にし、Speaker Embeddingを選びます。
3. 設定を保存し、「声を試す」で確認します。

同梱の起動用batは **v4-Large-Quantized/int8-weight-only・bf16** を使用し、`http://127.0.0.1:8088` で接続します。初回はモデルの取得・読み込みが完了するまで待ってください。

声はVRMファイルごとに記憶します。各VRMで一度登録すれば、以降はモデル変更時に自動で切り替わります。未登録のモデルは文字のみで返答します。VRMやEmbeddingを移動した場合は選び直してください。

導入条件・既存モデルの利用・トラブル対処は[TTS_SETUP.md](TTS_SETUP.md)にまとめています。

## 更新とデータ

既存環境の更新には **Update.zip** を使います。

1. トレイからアプリを完全に終了します。
2. 更新ZIPをすべて展開し、中身をexeのあるフォルダーへコピーします。
3. `apply_update.bat` を実行し、従来のexeから起動します。

元のアプリファイルは `backup-before-v（更新先バージョン）` に退避します。対応する更新元バージョンは各Releaseの説明をご確認ください。

設定・会話・関係は `%APPDATA%\vrm-desktop-companion\companion.json` に保存します。会話はキャラクターごとに最大100往復を保持し、LLMへは設定した範囲を送信します。VRM本体はコピーせずファイルの場所を記憶します。APIキーはOS機能で別ファイルへ暗号化保存します。別PC・別のWindowsユーザーへの移行ではキーを登録し直してください。

## 詳しい説明

- [USAGE.md](USAGE.md)：表示・吹き出し、会話、モーション、タッチ、手・衣服、好感度の設定。
- [TTS_SETUP.md](TTS_SETUP.md)：Irodori-TTSサーバーの導入と音声設定。
- [UPDATE.md](UPDATE.md)：バージョンごとの更新履歴。
- [VALIDATION.md](VALIDATION.md)：検証内容と制限。

表情・口パク・衣服の動きはモデルの骨や表情データに依存します。音声認識・長期記憶は未実装で、アプリは未署名です。クラウドLLMでは会話テキストを接続先へ送り、API利用料金が発生します。VRM・音声・Speaker EmbeddingはLLMへ送りません。

## ソースから起動

Node.jsを用意し、リポジトリのフォルダーで実行します。

```powershell
npm ci
npm run build
npm test
npm start
```

Windows版の作成は `npm run package:win` です。Gitにはソースを登録し、配布用のSource.zipにはビルド済みの描画コードも含めます。

## Ollamaをかんたん導入

`install_ollama.bat`をダブルクリックすると、Ollamaの導入とVRAMに応じた初期モデルの取得ができます。詳しくは[Ollama導入手順](OLLAMA_SETUP.md)をご覧ください。


名前と性格・口調はVRMファイルごとに保存・復元できます。設定後は「設定を保存」を押してください。



### モデルの描画

高画質固定で描画し、MToon本体材質はすべて陰影なしで表示します。画像に描かれた陰影・ハイライトと輪郭線は維持します。元VRMのファイルを変更せず、設定操作は不要です。
