# VRM Desktop Companion

好きなVRMモデルをデスクトップに表示して、Ollama／LM StudioのローカルLLMと文字で会話するWindows向けプロトタイプです。

## 通常の操作

- 起動するとキャラクターだけを表示します。操作バーや設定画面は常時表示しません。
- **左クリック（反応部位以外）**：「どうしたの？」の吹き出しと、小さな会話入力ウィンドウを開きます。
- **右クリック**：話しかける・設定・会話履歴・VRM選択・表示・位置リセット・終了のメニューを開きます。
- **タスクトレイのアイコンをクリック**：同じメニューを表示します。左右どちらのクリックでも利用できます。
- **反応部位以外を左ボタンでドラッグ、またはShift＋ドラッグ**：位置を移動します。ドラッグ終了では会話を開きません。
- キャラクターの周囲の余白は、背後のウィンドウへクリックを通します。判定はモデルのメッシュ形状を使うため、テクスチャの透明な穴などで完全一致しない場合があります。

発言は伺か風の、名前としっぽの付いた淡いクリーム色の吹き出しに表示します。吹き出しは最初はキャラクターの隣に表示します。上部の名前欄をドラッグして自由に移動でき、キャラクターと独立して位置を保存・復元します。設定の「吹き出しの位置を戻す」でキャラクターの隣へ戻せます。モニターが外れて操作できなくなった場合だけ画面内へ戻します。設定でインストール済みフォント名を候補から選択または直接入力し、文字サイズを8〜72pxで指定できます。フォント未導入時は代替フォントを使用します。通常7〜45秒で閉じ、×でも閉じられます。長い返答は吹き出し内をスクロールして読めます。全文は会話履歴にも保存されます。

## Windows版の起動と更新

初回は実行ファイル入りのWindows版ZIPをすべて展開し、`VRM-Desktop-Companion.exe` を起動してください。Node.jsは不要です。

0.1.0〜0.1.9から差分更新する場合：

1. トレイメニューからアプリを完全に終了します。
2. 更新ZIPを展開し、中身の `apply_update.bat` と `update-files` などを、exeのあるフォルダーへ置きます。
3. `apply_update.bat` を実行します。
4. 従来のexeから起動します。

元ファイルは `backup-before-v0.1.10` に保存します。会話履歴、名前、性格、LLM設定、VRMのパスは引き継ぎます。戻す場合はアプリを終了し、バックアップ内のappフォルダーをresources/appへ戻してください。app.asarがあればresourcesへ戻します。

## 最初の設定

1. キャラクターの右クリックまたはトレイのクリックから「VRMを選ぶ」で `.vrm` を読み込みます。VRM 0.x／1.0に対応します。モデル未選択時はオリジナルの簡易3Dキャラクターです。
2. [Ollama](https://ollama.com/download/windows)をインストール・起動し、PowerShellでモデルを用意します。

```powershell
ollama pull qwen3:8b
```

3. 右クリック→「設定」で接続方式Ollama、URL `http://127.0.0.1:11434` を指定します。
4. 「モデル取得」→モデルを選択→「設定を保存」。
5. 左クリックで入力窓を開いて話しかけます。

小さめのモデルから始めたい場合は `qwen3:4b` も使えます。モデルの初回取得には通信が必要です。LM Studioではモデルをロードしてローカルサーバーを起動し、接続方式LM Studio、URL `http://127.0.0.1:1234` を指定してください。

本アプリからのLLM接続先はループバックのHTTPサーバーに限定しています。ローカルサーバー側による外部転送の設定までは制御しません。

## 会話入力と履歴

- Enterで送信、Shift+Enterで改行。日本語変換の確定中は送信しません。
- Escapeまたは入力窓の×で閉じます。
- 入力窓はキャラクターと独立しています。ドラッグして置いた場所を保存し、会話を開き直したときやアプリ再起動後にも復元します。キャラクターを動かしても入力窓は追従しません。モニターを外して入力窓の位置が画面外になった場合に限り、画面内へ戻します。
- 返答の生成中は停止ボタンを使えます。通信失敗・停止時は入力文を残します。
- 返答が成功すると入力窓を閉じ、発言を吹き出しに表示します。
- 設定・履歴の画面は×で非表示になります。完全終了はトレイの「終了」です。

設定画面で名前・性格・口調・会話を送る範囲・モデル・大きさ・向き・最前面表示を変更できます。

## 表示とショートカット

まばたき、呼吸、柔らかい待機モーション、文字に合わせた口パク、簡単な笑顔に対応します。

「設定」→「しぐさ」で、口パクと待機モーションのON/OFF、動きの強さを変更できます。「動きを試す」はLLM未接続でも利用できます。変更した設定は先に保存してください。

口パクは返答や「どうしたの？」などの表示テキストから、母音の口形を切り替える疑似動作です。音声は出ず、発音に正確に同期するものではありません。VRM側にaa/ih/ou/ee/ohなどの口の表情が必要です。表情が一部だけなら利用できる口形へ切り替えます。口の表情がまったくないモデルでは口は動きません。

待機モーションは、ゆっくりした体重移動を思わせる腰・背中の傾き、呼吸、首の傾き、肩・肘・手首の控えめな揺れを組み合わせています。元の姿勢へ少しずつ加算し、無効にすると元の姿勢へ滑らかに戻ります。モデルの体形や衣装によっては腕の重なり方が違うため、強さを調整してください。

大きさは0.5〜10.0倍まで設定できます。ウィンドウと描画領域も拡大し、ウィンドウ内で全身が入るようカメラを調整します。画面サイズによる縮小や、画面端への押し戻しは行いません。画面外へ自由に移動でき、複数モニターの境界もそのまま越えられます。画面外へ出た部分は画面の境界で見えなくなります。見失った場合はトレイの「位置をリセット」を使ってください。吹き出しと入力窓の位置はキャラクターと独立して保持します。

- `Ctrl+Alt+C`：会話入力窓を開く
- `Ctrl+Alt+M`：キャラクターのクリック操作を一時的に無効／解除

クリック操作を無効にしてもトレイメニューは利用できます。場所が分からなくなったときは「位置をリセット」を選んでください。他アプリとショートカットが重複した場合はトレイを利用してください。

## 保存先

Windowsの `%APPDATA%\vrm-desktop-companion\companion.json` に設定と会話を保存します。最大100往復を保存し、LLMには設定した範囲だけを送信します。VRMファイル自体はコピーせず、選んだファイルのパスを記憶します。

## タッチ反応（0.1.5）

VRMを読み込むと、マウスとタッチで次の反応を行います。頭・顔をタップすると驚き、頭を18px以上スワイプすると照れます。胸・臀部のタップ・スワイプは恥ずかしがり、10秒以内にこれらへの操作が連続して3回以上になると怒ります。胸と臀部の操作は合算し、スワイプは離すまでを1回と数えます。頭への操作、通常の会話開始、10秒超の間隔で回数をリセットします。ジェスチャーは同じ部位で離すと確定し、途中キャンセルは数えません。頭や胸を使って移動するときはShiftを押しながらドラッグしてください。

設定の「ふれあい」で無効化や反応範囲の調整ができます。判定はVRMの骨とメッシュによる概算で、臀部は背面のみです。衣服・髪・装飾などによって一致しない場合があります。簡易デモキャラは対象外です。照れ用のblush/shy/embarrassed、驚きのsurprised、怒りのangryなどモデルにある表情を使用します。照れ表情がなければ笑顔を使い、専用表情がない場合も首・上半身のしぐさと吹き出しで反応します。頬が赤くなるかはモデルの表情データに依存します。

## LLMによるタッチ反応（0.1.7）

設定でLLMモデルを選択・保存している場合、タッチのセリフを自動生成します。性格・口調、直近最大3往復の会話、触った部位、操作、感情、連続回数を渡します。表情としぐさはすぐ反応し、生成後に吹き出しと口パクを表示します。感情は従来のルールで決定し、連続3回以上では怒りを指定します。セリフの内容は使用モデルに依存します。

連続操作は350ms待って最新の操作にまとめ、古い生成を取り消します。通常会話を優先し、会話中のタッチは表情・しぐさのみで反応します。会話開始、設定保存、モデル変更、クリック無効化、非表示などで古い生成を取り消します。タッチの返答は通常の会話履歴へ追加しません。

モデル未選択なら固定セリフを使います。サーバー停止・モデル未ロード・空返答・15秒のタイムアウトなどでも固定セリフへ戻ります。Ollamaでは初回にモデルを読み込む場合があるため、必要なら先に通常の会話で読み込んでください。LM Studioはサーバー側でモデルをロードしておいてください。

## 共通の衣服ドラッグ（0.1.8）

「スカート」「Skirt」「コート」「Coat」「ジャケット」「Jacket」を名前に含むボーン列を自動検出します。スカートの裾付近をクリックしたままドラッグすると、つかんだ列の裾側2区間が追従します。離すと滑らかに元へ戻ります。体・髪などをつかまないよう、スカートのボーンにウェイトが割り当てられたメッシュだけを判定します。裾をつかんで動かさずに離すと通常の会話を開きます。ドラッグを完了すると驚く反応をし、LLM設定済みならセリフも生成します。

設定の「衣服の操作」で有効・無効を選べます。マスコット移動はShift＋ドラッグ、または裾以外をドラッグしてください。ドラッグ中のフォーカス喪失・キャンセルは操作を中断します。モデル変更・向きや大きさの変更・無効化時は元に戻します。動かす距離と角度に上限を設け、通常の揺れもの計算の前に操作による変形を取り除いて蓄積を防ぎます。

これはボーンを使った簡易変形で、布の物理シミュレーションや厳密なつまみ点の固定ではありません。スカートのボーンがないモデル、別名のボーンや特殊な階層、裾にウェイトがないモデルなどは自動検出できません。見た目・貫通の程度はモデルに依存します。モデルファイルは変更・同梱しません。

### 0.1.9 の修正

揺れものボーンの回転値が描画用行列へ反映されず、裾を引いた反応だけが出る不具合を修正しました。操作時と復元時に行列を明示的に更新します。

### 0.1.10 の修正

コート・ジャケットのボーン名も検出対象に加えました。対象の衣服ボーンがない場合はドラッグを開始せず、通常の操作に戻ります。表情モーフが多いモデルでクリック判定が重くなるため、有効なモーフだけを計算し、同じ頂点の変形計算を判定ごとに再利用するように変更しました。ホバー判定は60ms以上の間隔を空け、クリック・ドラッグの開始判定は直ちに行います。
